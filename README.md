# 💡 Dynamic Programming Practice Problems

This repository contains a wide variety of classical and advanced problems solved using **Dynamic Programming (DP)** in C++. Each file corresponds to a specific problem and includes efficient DP-based solutions.

## 📄 List of Problems

-- 🎒 **01knapsack.cpp** — Classic 0/1 Knapsack problem using DP.  
-- 💰 **Coinchangecountways.cpp** — Count the number of ways to make a sum using given coins.  
-- 📝 **EditDistance.cpp** — Minimum operations to convert one string into another.  
-- 🎯 **TargetSum.cpp** — Number of ways to assign '+' and '-' signs to reach a target.  
-- 🧗 **climbingstair.cpp** — Number of ways to climb stairs taking 1 or 2 steps.  
-- 🪙 **coinchangemincoincount.cpp** — Find the minimum number of coins needed to reach a target amount.  
-- 🔢 **countnoofsubset.cpp** — Count the number of subsets that sum up to a target.  
-- ⚖️ **countnoofsubsetwithgivendiff.cpp** — Count subsets with a given difference in their sums.  
-- 🔐 **decodeways.cpp** — Number of ways to decode a digit string (e.g., 1 = A, 2 = B, etc.).  
-- ❌ **deleteopfortwostring.cpp** — Minimum deletions needed to make two strings equal.  
-- 🔄 **distinctsubsequence.cpp** — Count how many distinct subsequences of a string equal a target.  
-- 🧪 **fin.cpp** — Final or custom implementation (clarification needed).  
-- 🏚️ **houserobber.cpp** — Maximum sum from non-adjacent elements (House Robber I).  
-- 🏠 **houserobber2.cpp** — Variation of House Robber problem where houses are in a circle.  
-- ✔️ **isSubsequence.cpp** — Check if one string is a subsequence of another.  
-- 🔤 **lcsofthreestring.cpp** — Longest common subsequence among three strings.  
-- 📏 **longestcommonsubsequence.cpp** — Classic longest common subsequence problem.  
-- 🧵 **longestcommonsubstring.cpp** — Find the length of the longest common substring.  
-- ❤️ **longestpalindromicsubsequence.cpp** — Find the longest subsequence that is a palindrome.  
-- 🔁 **longestrepeatingsubsequence.cpp** — Find the longest subsequence that appears at least twice.  
-- 🧮 **matrixchainmultiplication.cpp** — Optimize the order of matrix multiplication to minimize operations.  
-- 🧍 **minclimbingstair.cpp** — Minimum cost to climb to the top of stairs.  
-- ➕ **minnoinstertiontomakepalindrone.cpp** — Minimum insertions to make a string a palindrome.  
-- ➖ **minnoofdeltomakepalindrome.cpp** — Minimum deletions to make a string a palindrome.  
-- 🔁 **minnumofdelansins.cpp** — Combined minimum number of deletions and insertions to make a palindrome.  
-- ⚖️ **minsubsetdiffsum.cpp** — Find the minimum difference between two subset sums.  
-- 🧩 **paritionequalsubset.cpp** — Check if an array can be partitioned into two equal sum subsets.  
-- ✂️ **plaindromepartition2.cpp** — Minimum number of cuts to split a string into palindromic substrings.  
-- 🧾 **printlcs.cpp** — Print the actual longest common subsequence.  
-- 📘 **printshortestcommonsupersequence.cpp** — Print the shortest common supersequence of two strings.  
-- 🪚 **rodcutting.cpp** — Maximize profit by cutting a rod into pieces.  
-- 🔗 **shortestcommonsupersequence.cpp** — Find the length of the shortest supersequence that contains two strings.  
-- 🎯 **subsetsumproblem.cpp** — Determine if a subset with the given sum exists.  
-- 🔢 **trifib.cpp** — Find the n-th number in the Tribonacci sequence.  
-- 🃏 **wildcardmatching.cpp** — Pattern matching using `*` (matches any sequence) and `?` (matches any one character).
